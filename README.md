# isaac-multi-run-timer

`isaac-multi-run-timer` is a mod for [_The Binding of Isaac: Repentance_](https://store.steampowered.com/app/1426300/The_Binding_of_Isaac_Repentance/). It tracks the total amount of time that passes while in-game, skipping the time that passes when in the main menu. The idea is to automatically track the time for long speedrun categories (such as Dead God%).

Subscribe to the mod on [the Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3795046419).

To see the timer, enter the "Multi-Run Timer" custom challenge.

This mod is written in [TypeScript](https://www.typescriptlang.org/) using the [IsaacScript](https://isaacscript.github.io/) framework.
